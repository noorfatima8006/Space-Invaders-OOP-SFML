# Space Invaders

A Space Invaders game developed in C++ using SFML and object-oriented programming.

## Features

- Player movement and shooting
- Multiple enemy types
- Collision detection
- Score and lives system
- Sound effects and background music
- Graphical interface using SFML

## Technologies Used

- C++
- SFML
- Visual Studio
- Object-Oriented Programming

## How to Run

1. Download or clone the repository.
2. Open `SMFLREAL.sln` in Visual Studio.
3. Select `Debug` and `x64`.
4. Build and run the project.
