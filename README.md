# Space Invaders

A Space Invaders game developed in C++ using SFML and object-oriented programming.

## Features

- Player movement
- Shooting system
- Enemy movement
- Collision detection
- Score system
- Sound effects
- Graphical interface using SFML

## Technologies Used

- C++
- SFML
- Visual Studio
- Object-Oriented Programming

## How to Run

1. Download or clone the repository.
2. Open `SMFLREAL.sln` in Visual Studio.
3. Select the x64 Debug configuration.
4. Build and run the project.
